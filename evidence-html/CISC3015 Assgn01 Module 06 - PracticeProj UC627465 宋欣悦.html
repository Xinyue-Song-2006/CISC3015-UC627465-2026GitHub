Handle missing data: - For continuous attributes (e.g., age), replace missing values with the mean. - For categorical attributes (e.g., smoker), replace missing values with the most frequent value. - Update the data types of the respective columns. - Verify the update using df.info() .

Code · In [8]
# smoker is a categorical attribute, replace with most frequent entry
is_smoker = df['smoker'].value_counts().idxmax()
df["smoker"] = df["smoker"].replace(np.nan, is_smoker)

# age is a continuous variable, replace with mean age
